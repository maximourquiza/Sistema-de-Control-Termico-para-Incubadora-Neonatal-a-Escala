Cómo conectar

  1. Emparejá el HC-05 desde Bluetooth en Windows.
  2. Cerrá PuTTY para liberar el puerto serie.
  3. Pulsá Conectar y elegí el puerto del HC-05: actualmente COM5.

Usá Chrome de escritorio. Abrir el puerto desde esta página establece la conexión; no hace falta abrir PuTTY primero. Si Windows cambia el número de COM, seleccioná el nuevo.
